# Windows Server 2025 — Planned domain lab

[Project home](../../README.md) · [Inventory](../../architecture/inventory.md)

My VMware environment includes a Windows Server 2025 guest with a recorded Desktop Experience installation. I plan to use it for AD DS, DNS and Windows authentication-monitoring exercises.

Domain promotion, DNS configuration, client joins and any migration to Proxmox are not yet validated in this record. The next case study will document isolated placement, configuration, tests and audit telemetry before treating the domain role as complete.
